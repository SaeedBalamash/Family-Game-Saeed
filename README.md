# 🏆 بطولة العائلة

منصة مسابقات عائلية باللغة العربية لجلسات من 6 إلى 10 أشخاص (كبارًا وصغارًا): فرق متوازنة، 10 فئات من التحديات، شاشة عرض للتلفاز، لوحة نتائج حية، أدوار إقصائية وتتويج.

تطبيق ويب خفيف بلا أي اعتماديات ولا خطوة بناء.

## التشغيل

**الأبسط:** افتح `index.html` في المتصفح مباشرة (يعمل دون إنترنت؛ الخط العربي يُحمَّل من Google Fonts إن توفر الاتصال).

**مع التلفاز الذكي وجوال التحكم (على الواي فاي نفسه):**

```bash
node server.js          # أو: npm start  (المنفذ 3000، أو: node server.js 8080)
```

ثم افتح العناوين التي يطبعها الخادم:

| الشاشة | العنوان | الوظيفة |
|---|---|---|
| المقدّم | `http://localhost:3000/` | الإعداد والتحكم (ويمكن استخدامها شاشةَ عرض أيضًا) |
| التلفاز | `http://<IP>:3000/?view=tv` | عرض فقط بملء الشاشة |
| الجوال | `http://<IP>:3000/?view=remote` | أزرار التحكم + **الإجابة الصحيحة سرًّا للمقدّم** |

بدون الخادم يمكن فتح نافذة التلفاز ولوحة التحكم على الجهاز نفسه (زر 📱 في اللعبة) وسحب نافذة التلفاز إلى الشاشة الكبيرة.

## طريقة اللعب باختصار

1. **اللاعبون:** اسم + صورة رمزية + فئة عمرية (طفل/ناشئ/بالغ) + مستوى.
2. **الإعدادات:** فرق (2–4) أو فردي · مجموعات ثم إقصائيات / دوري نقاط / إقصائيات مباشرة · الفئات · الوقت.
3. **الفرق:** توزيع تلقائي يوازن الأعمار والمستويات، مع إمكانية التعديل اليدوي.
4. **اللعب:** يتناوب الفرق وأعضاؤها على الإجابة. سهل 10 · متوسط 20 · صعب 30. الخطأ يمنح المنافس فرصة **الخطف** بنصف النقاط، والجولة الأخيرة مضاعفة.
5. **التعادل:** يُحسم بالإجابات الصحيحة ← الأسئلة الصعبة ← الأخطاء الأقل ← **سؤال الحسم** (الأسرع يفوز) أو القرعة.

اختصارات المقدّم: `مسافة` التالي · `1-4` الإجابة/المستوى · `C` صحيحة · `X` خاطئة · `P` المؤقت · `U` تراجع · `F` وضع التلفاز · `M` الصوت.

## بنك الأسئلة

170 سؤالًا وتحديًا في `js/questions.js` موزعة على 10 فئات × 3 مستويات: تمثيل صامت، معلومات عامة، ألغاز ومنطق، أفلام وتلفزيون، تاريخ، اللغة العربية، ثقافة وتراث، قوة الملاحظة، ذاكرة، تحديات حركية.

- لا يتكرر سؤال داخل البطولة الواحدة، وترتيب الخيارات يُخلط في كل مرة.
- من صفحة «بنك الأسئلة» يمكن إضافة أسئلتك (مع تحقق تلقائي: خيارات مكررة، إجابة ناقصة، سؤال مكرر…) واستيرادها/تصديرها بصيغة JSON:

```json
[{ "cat": "general", "diff": "easy", "type": "mcq", "q": "ما عاصمة فرنسا؟",
   "options": ["باريس", "لندن", "روما", "مدريد"], "answer": 0, "exp": "باريس عاصمة فرنسا." }]
```

`type`: ‏`mcq` (اختيارات) · `open` (إجابة نصية في `answer`) · `charades` (الكلمة في `word`) · `physical` (المدة في `seconds`).

## البنية والاختبارات

```
index.html · css/style.css
js/engine.js      منطق البطولة (بلا DOM): التوزيع، الأدوار، النقاط، التعادل، الشجرة
js/questions.js   بنك الأسئلة
js/app.js         الواجهة: الإعداد، شاشة العرض، لوحة المقدّم، جوال التحكم
js/sound.js       مؤثرات صوتية مولَّدة (WebAudio)
server.js         خادم اختياري للمزامنة عبر الشبكة المحلية
tests/            اختبارات المحرك + اختبار متصفح شامل
```

```bash
npm test            # اختبارات المحرك: 300 بطولة آلية بكل الصيغ، النقاط، عدم التكرار، صحة البنك
npm run test:e2e    # Playwright: خمس بطولات كاملة بالنقر على الواجهة من الإعداد إلى التتويج
```
